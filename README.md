# 취업/이직 미니 진단

상담 예약자에게 발송하는 취업/이직 미니 진단 페이지.

## 구성
- `index.html`: 진단 페이지 (단일 파일)
- `apps-script/Code.gs`: 응답을 구글 시트에 쌓는 Apps Script

## 배포
1. Vercel에서 이 저장소를 Import (Framework: Other, 빌드 설정 없음)
2. 응답 시트에 `apps-script/Code.gs`를 웹 앱으로 배포 (실행: 나, 액세스: 모든 사용자)
3. 웹 앱 URL을 `index.html`의 `SHEET_ENDPOINT`에 입력

## 동작 방식
- 기본 주소: 실제 진단 모드. 이름, 연락처, 구분, 연차를 입력받고 고민과 12문항 응답으로 점수와 유형을 계산
- 링크에 고객 정보를 붙이면 그만큼 입력 단계가 줄어듦
  - `name`: 이름 (예: `?name=홍길동`)
  - `phone`: 연락처, 화면에는 안 보이고 시트에만 저장
  - `exp`: DB의 경력 기간 원문 (예: `5년 이상 ~ 7년 미만`) 또는 `stage`: new, jr, mid, sr
  - 이름과 연차가 모두 있으면 기본 정보 화면 없이 바로 고민 질문으로 시작
- 주소 끝에 `?demo=1`을 붙이면 예시 고객 3명으로 동작하는 시연 모드
- 결과지가 열리면 응답이 시트로 전송되고, Apps Script가 PDF 결과지를 만들어 연락처 옆 열에 링크를 남김
