# 취업/이직 미니 진단

상담 예약자에게 발송하는 취업/이직 미니 진단 페이지.

## 구성
- `index.html`: 진단 페이지 (단일 파일)
- `apps-script/Code.gs`: 응답을 구글 시트에 쌓는 Apps Script

## 배포
1. Vercel에서 이 저장소를 Import (Framework: Other, 빌드 설정 없음)
2. 응답 시트에 `apps-script/Code.gs`를 웹 앱으로 배포 (실행: 나, 액세스: 모든 사용자)
3. 웹 앱 URL을 `index.html`의 `SHEET_ENDPOINT`에 입력

## 동작 방식
- 모든 고객에게 같은 링크(기본 주소)를 일괄 발송
- 고객이 이름과 연락처를 입력하면 [ZB] SD 2.0 시트 DB RAW 탭에서 앞서 남긴 응답을 찾아 "남겨주신 답변" 페이지를 보여줌 (이름과 연락처가 모두 맞아야 조회)
- 못 찾으면 구분과 연차를 직접 선택받고 진행
- 고민과 12문항 응답으로 점수, 유형, 추천 프로그램을 계산하고 결과지가 열릴 때 응답 시트로 전송
- Apps Script가 PDF 결과지를 만들어 응답 시트 연락처 옆 열에 링크를 남김
- 링크에 `?name=홍길동&phone=01012345678`을 붙이면 입력 없이 바로 조회 (개별 발송용, 선택)
- 주소 끝에 `?demo=1`을 붙이면 예시 고객 3명으로 동작하는 시연 모드
